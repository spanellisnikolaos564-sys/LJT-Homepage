# LJT-Homepage

Personal academic homepage of Junteng Liu, built on the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template (forked).

- About / home page: `_pages/about.md`
- Publications: `_publications/` (listed at `/publications/`)
- Site-wide configuration: `_config.yml`
- Navigation menu: `_data/navigation.yml`
